# H7_MP3_Player — MP3-плеер на WeAct MiniSTM32H7xx (STM32H743VIT6) + PCM5102A

Плеер читает MP3 с microSD, декодирует и выводит звук через ЦАП PCM5102A по I2S.
На экране 0.96" — номер и название трека, время и полоса прогресса.

## Подключение PCM5102A (фиолетовый модуль GY-PCM5102)

| PCM5102A | Плата WeAct (разъём P1) | Сигнал     |
|----------|-------------------------|------------|
| BCK      | **PB13**                | I2S2_CK    |
| LCK      | **PB12**                | I2S2_WS    |
| DIN      | **PB15**                | I2S2_SDO   |
| SCK      | **GND**                 | ЦАП сам берёт такт из BCK |
| VIN      | 5V (или 3V3)            | питание    |
| GND      | GND                     |            |

Перемычки на обороте модуля (если нет звука — проверь их первым делом):
`H1L FLT = L`, `H2L DEMP = L`, `H3L XSMT = H` (H — звук не заглушён), `H4L FMT = L` (формат I2S).

Наушники или усилитель подключаются к 3.5 мм гнезду модуля.

## SD-карта

* FAT32 или exFAT, любой объём.
* Файлы `.mp3` в корне и в папках (до 4 уровней вложенности), не больше 256 штук.
  Служебные файлы macOS (`._*`, `.Trashes`) пропускаются.
* Поддерживаются любые частоты MP3 (8–48 кГц), моно и стерео, CBR/VBR, ID3-теги с обложкой.
* Русские названия показываются транслитом (`Кино` → `Kino`): в шрифте экрана нет кириллицы.

## Управление (кнопка KEY, PC13)

* короткое нажатие — следующий трек
* долгое (0,8 с) — пауза / продолжить
* на экране «NO MP3 FILES» — нажатие пересканирует карту

Синий светодиод (PE3) горит во время воспроизведения. Карту можно вынимать и вставлять на ходу.

## Где что в коде

| Файл | Что делает |
|------|------------|
| `Core/Src/mp3_player.c` | главная логика: состояния, экран, кнопка |
| `Core/Src/mp3_stream.c` | файл → PCM (FatFs + minimp3), пропуск ID3 |
| `Core/Src/audio_out.c`  | I2S2 + DMA1 Stream1, аудио-такт от PLL3 (точно 44.1/48 кГц) |
| `Core/Src/playlist.c`   | список mp3 на карте, транслит |
| `Core/Src/sd_card.c`    | SD-карта на SDMMC1 (4 бита, 15 МГц) |
| `Core/Src/FatFs/`       | FatFs R0.16 (только чтение, длинные имена UTF-8, exFAT) |
| `Core/Src/minimp3/`     | MP3-декодер minimp3 (CC0), всегда собирается с -O2 |
